## About This Project

![GitHub last commit](https://img.shields.io/github/last-commit/crashbug01/30DaysJSChallenge-Day2)<br>

A Clock made with CSS and JS. It serves as the Day 1 entry for the "30 Days of JavaScript" challenge by Wes Bos.

### Key Learning Objective

- DOM Manipulation: The core focus of this project is using JavaScript to directly manipulate the Document Object Model (DOM) to create a smooth, visual representation of time.

- Selecting Elements: Using document.querySelector() to target specific clock hand elements (seconds, minutes, and hours) within the HTML.

- Dynamic Styling: Accessing the .style property of DOM elements to programmatically update CSS variables.

- Transforming Elements: Applying rotate() values via the transform property to change the orientation of elements based on real-time data.

- Timed Updates: Utilizing setInterval() to trigger DOM updates every second, ensuring the UI remains in sync with the system clock.
